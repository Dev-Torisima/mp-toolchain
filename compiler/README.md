# mp言語 コンパイラー
mp言語用のコンパイラーです  

## 概要
コンパイラーの対応するのはWindows（32bit、64bit、ARM64版）、Linux（64bit、arm、arm64版）のみです（試験版は除く）  
原則、Windows10以降での使用を想定しています  
出力ファイルはhtmlまたはWindowsの64bit実行ファイルです  
これはすべての64bitアプリを実行できるWindowsで使用可能です  

## ライセンス  
MITライセンス（オリジナル部分に限る）  


## 注意
コードファイルのエンコードは指定されない場合、UTF-8として受け入れられます
デフォルトでは最適化が行われます

## 使い方
mpcom.exe または mpcom を引数とともに、コーンソール上で起動します  
その際の引数は以下です（「（）」で囲まれる引数は任意で、複数指定はスペースで区切ってください）   
### --version  
内部で使用しているシステムのバージョンの関係で意図されるバージョンではない場合があります
   
### help  
ヘルプを表示します
  
### （-no） （｛エンコード名｝） （｛出力形式｝） ｛コードファイルのパス｝ （｛中間出力ディレクトリ｝） ｛出力ファイルのパス｝     
この場合は出力ファイルが予定されるディレクトリに中間出力（一時ファイル）が生成されます 
「-no」は最適化を無効化します

｛エンコード名｝は  
- 「utf8」（UTF-8｜デフォルト値）  
- 「utf16」  
- 「utf32」  
- 「ascii」  
- 「utf16_l」（リトルエンディアンUTF-16）  
- 「utf16_b」（ビッグエンディアンUTF-16）
 
｛出力形式｝は  
- 「html」（ウェブサイト｜デフォルト値）  
- 「exe」（Windows 64bit 実行ファイル｜*1）  
*1：Windows向け、Linuxの64ビット向けのコンパイラーでのみ使用可能
